# Архитектура DejaView

Черновик. Схема и подробное описание появятся с командой.

Ядро: мультимодальный поиск (текст / фото / видео / аудио -> эмбеддинги -> векторный поиск -> результаты из TMDB).

Компоненты:
- Backend (API, поиск, БД) - dejaview-backend
- Frontend (SPA) - dejaview-frontend
- ML (эмбеддинги, векторный поиск) - dejaview-ml
- Инфраструктура (Docker, CI/CD) - dejaview-infra
